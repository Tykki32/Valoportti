# Valoportti

* `Valoportti816/` – ATtiny816-firmware (tarkka reunan keskiaika, I2C-orja). Katso `Valoportti816/README.md`.
* `ValoporttiESP32_multi_8_2/` – ESP32-S3 master (1–4 anturia, kalibrointi, mittaustesti, reunan kaappaus).
* `ValoporttiESP32_multi_8_1/` – edellinen ESP32-versio (alkuperäinen).
* `ValoporttiAttiny13_3_message/` – alkuperäinen ATtiny816-sketsi (vain kommentoitu, koodi ennallaan).
